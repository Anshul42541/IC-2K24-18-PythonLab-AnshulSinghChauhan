# Time and Space Complexity Analysis

##  Overview

This activity analyzes the Time Complexity and Space Complexity of 22 Python code snippets using Big-O notation.

##  Topics Covered

- Linear Complexity – `O(n)`
- Constant Complexity – `O(1)`
- Quadratic Complexity – `O(n²)`
- Logarithmic Complexity – `O(log n)`
- Exponential Complexity – `O(2^n)`
- Recursive Algorithms
- Nested Loops
- Arrays, Lists, Sets, and Dictionaries
- Matrix Operations

##  Objective

To understand how different Python programs perform as the input size increases and identify their time and space requirements.
