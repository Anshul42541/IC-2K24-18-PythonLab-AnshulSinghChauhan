# ⭐LAB-2 - Python Pattern Printing Programs

This Folder contains a collection of Python programs designed to practice pattern printing using loops and conditional statements.

These programs help beginners understand nested loops, iteration, and logical thinking in Python.

## 📂 Programs Included

| S.No. | Program Name | Description |
|---|---|---|
| 1 | Right Angle Triangle | Prints a right-angled triangle using stars (`*`). |
| 2 | Pyramid Triangle | Prints a centered pyramid pattern using stars (`*`). |
| 3 | Inverted Triangle | Prints an inverted triangle pattern using stars (`*`). |
| 4 | Square Pattern | Prints a square pattern using stars (`*`). |
| 5 | Rhombus Pattern | Prints a rhombus shape using stars (`*`). |

## 🛠️ Technologies Used

- **Language:** Python 3

- **Concepts:** 
  - Nested Loops
  - For Loops
  - Conditional Statements
  - Pattern Printing Logic
  - Use print() to move to the next line.


## 🎯 Learning Objectives

- Understand how nested loops work.
- Improve problem-solving skills.
- Learn row and column-based pattern logic.
