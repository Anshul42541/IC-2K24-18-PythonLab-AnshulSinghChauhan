## Overview
This repository contains five Python programs based on **Dictionary Data Structures**. These programs demonstrate how dictionaries can be used to store, manage, search, update, delete, and analyze real-world data.

# Q1. Student Database Management System
A student record management system using nested dictionaries.

**Features:**
- Add, update, delete, and display student records.
- Store student names and subject-wise marks.
- Calculate student averages and identify the topper.
- Find the highest scorer in each subject.
- Identify students scoring below 40.
- Group students according to grades.

**Concepts Used:** Nested dictionaries, loops, conditional statements, dictionary methods, and comprehensions.

### Q2. Employee Database Management System
An employee management system that stores employee details.

**Features:**
- Add, update, delete, and search employee records.
- Calculate department-wise payroll and headcount.
- Find the highest-paid employee in each department.
- Sort employees by salary.
- Calculate a 10% salary raise for employees earning below ₹50,000.
- Find the department with the highest average salary.

**Concepts Used:** Nested dictionaries, `setdefault()`, `sorted()`, lambda functions, and dictionary comprehensions.

### Q3. Library Record Management System
A library management system that maintains book records and issue/return information.

**Features:**
- Add books and manage available copies.
- Issue and return books.
- Prevent issuing unavailable or duplicate books.
- Limit each member to a maximum of two books.
- Search for books.
- Find books by author, unavailable books, and never-issued books.
- Identify members holding more than one book.

**Concepts Used:** Nested dictionaries, lists inside dictionaries, loops, conditions, `setdefault()`, and comprehensions.

### Q4. Word Frequency Counter
A program that analyzes text and counts the frequency of each word.

**Features:**
- Convert text to lowercase and remove punctuation.
- Count word frequency using dictionaries.
- Display the top N most frequent words.
- Find words that appear exactly once.
- Invert the frequency dictionary.
- Group words according to their length.
- Search for a particular word.

**Concepts Used:** String manipulation, dictionaries, `.get()`, `sorted()`, `setdefault()`, and dictionary comprehensions.

### Q5. Phone Directory Management System
A contact management system that stores phone numbers, email addresses, and cities.

**Features:**
- Add, update, delete, and search contacts.
- Add multiple phone numbers to a contact.
- Validate 10-digit phone numbers.
- Prevent duplicate phone numbers across contacts.
- Search contacts using partial names.
- Find contact names using phone numbers (reverse lookup).
- Group contacts by city.
- Display contacts with multiple phone numbers alphabetically.

**Concepts Used:** Nested dictionaries, lists, string methods, dictionary comprehensions, reverse lookup, and `setdefault()`.



## Python Concepts Practiced

1. Dictionary creation and manipulation.
2. Nested dictionaries.
3. Dictionary methods: `get()`, `update()`, `pop()`, `popitem()`, and `setdefault()`.
4. Dictionary loops and iteration.
5. Dictionary and list comprehensions.
6. Sorting dictionaries using `sorted()` and lambda functions.
7. Grouping and aggregation.
8. Searching and reverse lookup.
9. Input validation and exception handling.
