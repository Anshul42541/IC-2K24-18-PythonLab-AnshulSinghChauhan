# Lab 4 – Algorithm Optimization

Today's Lab Work contains three Python programs based on algorithms and their optimization.

## Problems

### 1. Sum of Prime Numbers
- Find the sum of all prime numbers below N.
- Implemented using:
  - Naive Approach
  - Square Root Optimization
  - Sieve of Eratosthenes

### 2. Count Pairs With a Given Sum
- Count the number of pairs whose sum equals the given target.
- Implemented using:
  - Nested Loops
  - Dictionary (Hash Map)

### 3. K-th Smallest Pairwise Sum
- Find the K-th smallest sum among all possible pairs.
- Implemented using:
  - Naive Approach
  - Two Pointers
  - Binary Search on Answer



## Language
Python 3

## Purpose
To understand how different algorithms and optimization techniques improve program execution time and efficiency.
